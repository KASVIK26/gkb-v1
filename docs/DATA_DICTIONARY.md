# Data dictionary

Generated by `agrihub kg publish-files` from the pydantic models in `curator/model/`; it cannot drift from the code.

## Identifiers

`<prefix>:<crop>:<local>` for crop-scoped types and `<prefix>:<local>` otherwise. Prefixes: Crop = `crop`, Variety = `var`, Gene = `gene`, QTL = `qtl`, Marker = `mk`, RefGene = `ref`, Disease = `dis`, Pathogen = `path`, Pathotype = `pt`, EnvTrigger = `env`, AgroZone = `zone`, Advisory = `adv`. Crop-scoped types: Advisory, AgroZone, Disease, EnvTrigger, Gene, Marker, QTL, RefGene, Variety. Claim ids are content hashes (`claim:<16 hex>`) of type, subject, object and qualifiers, so the same statement always has the same id.

## Evidence methods and weights

| Method | Weight |
|---|---|
| cloned_validated | 1.0 |
| official_document | 0.9 |
| diagnostic_marker | 0.85 |
| sequence_haplotype | 0.85 |
| field_multi_env | 0.8 |
| qtl_mapping | 0.7 |
| linked_marker | 0.65 |
| gwas | 0.6 |
| computational | 0.6 |
| field_single_env | 0.5 |
| controlled_env | 0.5 |
| curator_assertion | 0.5 |
| postulation_pedigree | 0.45 |
| review_statement | 0.35 |

A claim's score is `1 - prod(1 - w)` over independent sources (a source contributes its strongest evidence only); evidence found by a language model and not yet reviewed is multiplied by 0.6; evidence more than ten years old on race-structured claims by 0.8. Tiers: A >= 0.85, B >= 0.65, C >= 0.40, D below; a conflicting claim is capped at C. See `curator/graph/scoring.py` and `docs/QC_REPORT.md` (sensitivity of the tiers to these constants).
