How to read this graph
  1. Each shape is an entity — a variety, gene, disease, advisory… Colour and shape show its type (see the key). Bigger = more connections.
  2. Each arrow is one claim taken from a cited source, read from → to: “Sr33 confers resistance to stem rust”.
  3. Hover for a one-line meaning · click an entity to see everything linked to it · click a key item to hide that type.
  4. Line style is confidence: solid = tier A or B, dashed = C, dotted = D. Click a line to see the sources behind that claim.
